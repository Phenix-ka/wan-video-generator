# Demo samples

The two demo clips (`demo-clinic.mp4`, `demo-product.mp4`) are NOT committed to the repo — they are ffmpeg test-pattern videos, clearly labeled DEMO SAMPLE in the app. Regenerate them after cloning:

```sh
sh generate-samples.sh
```

They are placeholders only. Real demo videos need the GPU worker connected and a real Wan 2.2 render — never present these test clips as product output.
